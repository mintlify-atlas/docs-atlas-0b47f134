Relay is a full-stack end-to-end encrypted chat application built with Next.js and NestJS. Every message is encrypted in the browser using libsodium before it leaves your device — the server stores only ciphertext and can never read your conversations.

## What Relay does

Relay provides secure, real-time communication with a strong privacy guarantee:

- **End-to-end encrypted messaging** — AES-256-GCM encryption with per-conversation keys that the server never unwraps
- **Group conversations** — create group chats where each member gets their own wrapped copy of the conversation key
- **Temporary Chat mode** — enable ephemeral sessions where messages are never written to the database and are purged when the session ends
- **Encrypted media** — upload files encrypted client-side; the server stores only a Cloudinary URL, never the plaintext bytes
- **WebRTC 1:1 calls** — peer-to-peer audio and video calls that never touch the server; Relay relays only the signaling

## What the server sees

Relay is designed so that a compromised server learns as little as possible:

| Data | Server sees |
|---|---|
| Messages | Ciphertext + nonce only |
| Media files | Cloudinary URL of the encrypted blob |
| Keys | Only the public halves; private keys stay in your browser's IndexedDB |
| Metadata | Who talks to whom, when, and message size |

<Note>
Relay does not provide forward secrecy. If a conversation key is ever leaked, all history encrypted under that key is readable. See the [encryption page](/features/encryption) for the full threat model.
</Note>
